# Netflix-Inspired-Web
 # 🎬 Media Showcase Website

A fun and interactive web project featuring popular media characters and titles like Avengers, Batman, Squid Game, and more. Built using HTML, CSS, PHP, and image assets.

## 🚀 Features
- Responsive design with custom styling
- Media gallery with iconic characters
- Backend integration using PHP
- Clean and modular file structure

## 📁 File Overview
- `netflix.html` – Main landing page
- `net.css` – Styling for the site
- `netpage.php` – Backend logic
- `*.jpg` – Media images
- `logo.svg` – Site logo
- `README.md` – Project documentation

## 📦 How to Run
1. Clone the repo: `git clone https://github.com/yourusername/your-repo-name`
2. Open `netflix.html` in your browser
3. (Optional) Set up a local server for PHP files
